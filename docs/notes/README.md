# 问题卡片索引

只记录「卡住超过 20 分钟」的问题。每张卡片一个文件，命名 `YYYY-MM-DD-序号-简述.md`。

规则：
1. **当场记**，不要事后补——事后回忆会把「误判」洗掉，而误判是卡片里最有价值的一段。
2. 每天收尾花 15 分钟整理，当天不足一张则说明走得太顺，需要主动往深挖。
3. 每批结束把当批卡片汇总到下表的「批次」列。

## 模板

```md
# 简述

- 批次：Day N
- 模块：A1 / A2 / C4 …

## 现象
（错误信息、异常表现、错误数据，原样保留，不要转述）

## 误判
（我一开始以为是什么；这段是面试讲述的入口）

## 根因
（实际是什么，为什么）

## 方案
（怎么修的；放弃过哪些备选方案，为什么）

## 追问
（面试官继续问时，还能往哪里深挖）
```

## 一句话备注（不成卡，避免丢失）

- `TextDecoder` 的 `stream: true` 与 `decode()` 返回值：已并入 04 卡细节 1~3。
- `res.writableEnded` 判不出客户端断开：只在主动 `res.end()` 后为 true，客户端中止时仍是 false —— 服务端要自己置 `clientGone` 标志。
- `node --test` 的 glob 在 bash 里不展开 `**`：脚本里加引号交给 Node 自己展开。
- 并发编辑覆盖：磁盘文件被编辑器旧 buffer 保存覆盖，现象是"改动没生效"，先看 `mtime` 与内容。
- `pnpm i` 加新包会触发全量重装 `node_modules`：属预期提示。
